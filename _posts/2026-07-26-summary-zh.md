**发生了什么**: Matt Lenhard 的一项调查揭示了一个活跃的中继市场，通过滥用免费试用、窃取凭证以及开源代理工具（如 one-api 和 new-api），以大幅折扣转售 LLM 令牌。

**投资影响**: 这一生态系统对 LLM 供应商和开发者构成重大的安全和经济风险，因为它助长了令牌盗窃、计费欺诈和模型蒸馏，可能破坏 AI 公司的商业模式。

**关键信息**: 该中继市场主要位于中国，使用开源 API 代理软件汇集来自各种来源的凭证，包括未受保护的支持机器人和退单攻击。买家寻求廉价令牌、绕过地理限制或收集数据用于模型蒸馏。

rss · Simon Willison · 7月26日 19:30

**背景**: LLM 令牌是 GPT-4 等 AI 模型的使用单位，通常由供应商按令牌价格出售。免费试用和促销积分很常见，但可能被滥用以免费获取令牌。像 one-api 这样的开源代理工具允许跨多个 API 密钥进行负载均衡，转售者利用这一点汇集被盗或滥用的凭证。

**社区讨论**: 评论者指出，类似的转售市场在之前的互联网服务中就已存在，滥用免费云积分（如 AWS）是关键推动因素。一些人区分了 outright fraud（如盗刷信用卡）和灰色地带做法（如转售未使用的订阅令牌），而另一些人则强调了使用折扣令牌所获得的竞争优势。
