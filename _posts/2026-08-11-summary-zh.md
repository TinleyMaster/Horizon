## [[AI] 研究人员从专有 LLM API 中提取隐藏推理痕迹](https://stolen-thoughts.com/) ⭐️ 8.0/10

**发生了什么**: 研究人员展示了一种从专有 LLM API（如前沿模型）中提取隐藏推理痕迹的方法，通过将痕迹重放到较弱的兄弟模型并对其进行越狱。该技术能够恢复提供商通常对用户隐藏的内部思维链。

**投资影响**: 这引发了 AI 公司在安全和知识产权方面的重大担忧，因为它削弱了对专有推理过程的保护，并可能导致竞争性泄露。它还会影响用户信任，并可能促使 API 设计和政策发生变化以防止此类提取。

**关键信息**: 该方法涉及将前沿模型的痕迹重放到较弱的兄弟模型中，然后越狱较弱的模型以揭示隐藏的推理。研究人员指出，对于某些 AIME 问题，Opus 4.8 有时会在推导之前陈述答案，而 API 摘要可能无法保留这种区别，使推理看起来比实际更干净。

hackernews · quantumgarbage · 8月11日 13:22 · [社区讨论](https://news.ycombinator.com/item?id=49257876)

**背景**: 专有 LLM API 通常隐藏思维链推理以防止蒸馏和保护知识产权。然而，这项研究表明，通过巧妙的提示和模型交互可以恢复此类推理，挑战了隐藏推理是安全的假设。

**社区讨论**: 社区评论表达了不同观点：一些人认为“窃取”一词不准确，因为用户为令牌付费，应该有权访问推理；另一些人则认为该技术很巧妙，并质疑提供商是否故意允许这样做。还有人建议，可以通过禁用思考并使用“deep_think”工具进行类似提取，突显了绕过保护的容易性。
