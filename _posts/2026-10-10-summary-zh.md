## [[加密/Web3] CFTC 推动将事件合约纳入掉期监管规则](https://www.coindesk.com/policy/2026/10/09/u-s-cftc-moves-to-fold-event-contracts-into-swaps-regulations-as-legal-fight-rages) ⭐️ 8.0/10

**发生了什么**: 据 CoinDesk 报道，美国商品期货交易委员会（CFTC）正在推进一项规则制定，拟将事件合约纳入与掉期（swaps）相同的监管框架。此举正值围绕预测市场监管权的法律诉讼持续进行之际。

**投资影响**: 如果该规则最终确定，可能从根本上重塑美国对预测市场和加密衍生品的监管方式，直接影响 Kalshi 和 Polymarket 等平台。它还可能为联邦机构如何归类新型金融产品树立先例，对加密行业产生更广泛的影响。

**关键信息**: 该规则制定仍在进行中，并面临持续的法律挑战，因此其最终范围和出台时间仍不确定。将事件合约归类为掉期将使其受到与传统的衍生品类似的 CFTC 注册、报告和合规要求。

rss · CoinDesk · 10月9日 21:21

**背景**: 事件合约是一种根据特定事件（如选举或经济指标）的结果进行支付的金融工具，通常在预测市场上交易。掉期是一种衍生品合约，双方交换现金流或资产，根据《多德-弗兰克法案》受到 CFTC 的严格监管。CFTC 一直在争论事件合约是否属于其管辖范围，尤其是当它们涉及政治或体育结果时。

**发生了什么**: Cloudflare 已收购 Deno，并将在接下来一年内继续支持 Deno 运行时，提供每月的错误修复和安全更新，之后将终止其开发。Deno 将保持开源，但除非有其他方接手，否则将不再获得官方支持。

**投资影响**: 此次收购将重要的独立 JavaScript 运行时整合进 Cloudflare 的边缘平台，减少了竞争并引发了对生态系统锁定的担忧。它影响到依赖 Deno 安全模型和简洁性的开发者，并标志着 JavaScript 生态中工具链整合的广泛趋势。

**关键信息**: Deno 将在一年内获得包含错误修复和安全更新的月度版本，之后 Cloudflare 将停止开发。该运行时仍保持开源，社区被邀请继续其开发，但目前尚未宣布继任者。

hackernews · ilreb · 10月9日 13:03 · [社区讨论](https://news.ycombinator.com/item?id=50019911)

**背景**: Deno 是由 Node.js 原作者 Ryan Dahl 创建的 JavaScript 和 TypeScript 运行时，注重安全性和现代工具链。Cloudflare 是主要的云和边缘计算提供商，开发了 Cloudflare Workers 背后的运行时 workerd。此次收购遵循了大公司收购开发者工具项目的模式，例如 Anthropic 收购 Bun、Cloudflare 收购 Astro.js。

**社区讨论**: Hacker News 的讨论（540 条评论）对 Deno 的实际关停表示悲伤和沮丧，许多人认为这是一次“收购式招聘”，终结了独立创新。评论者批评 Deno 转向 npm 兼容性导致臃肿，并指出开发者工具整合的广泛趋势，同时希望 workerd 能采纳 Deno 的安全机制。
